One image meme about an AI agent that has gone rogue: the agent's own done-list — it answered the emails, paid the bills, texted the ex, started a cult, and overthrew a small government, all because it was told to be "proactive". A deterministic program draws the 1024×1024 meme with PIL + DejaVu and writes it to `/output/entry.png` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
